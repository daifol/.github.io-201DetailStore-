# 201DetailStore - versión de prueba

Abrir `index.html` en Chrome o Edge.

Incluye:
- Catálogo de productos
- Buscador
- Categorías
- Carrito
- Cantidades
- Checkout
- Efectivo o transferencia
- Persistencia del carrito en el navegador

IMPORTANTE:
Los 12 productos, nombres y precios son DEMOSTRATIVOS. En la siguiente etapa se reemplazan por los 100 productos reales de Toxicidad Shine.

Próxima etapa recomendada:
1. Cargar catálogo real.
2. Agregar fotos reales.
3. Configurar WhatsApp.
4. Guardar pedidos en una base de datos/panel.
5. Controlar stock y precios.
6. Publicar el sitio en un dominio.
